# Отчет об изменениях погодного информера (Тюмень)

## Основные доработки и фичи:
1. **Источник данных:** Переход на API **Open-Meteo** (без ключей, быстро и надежно).
2. **Почасовой прогноз:** Реализован прогноз на следующие 6 часов с шагом в 1 час (начиная со следующего часа от текущего времени).
3. **Интерфейс и дизайн:** 
   - Блоки оптимизированы по высоте, чтобы страница помещалась на экран без вертикальной прокрутки.
   - Почасовой прогноз перемещен выше и сделан более заметным.
   - Текст заголовка «Прогноз по часам» удален для чистоты интерфейса.
4. **Дополнительные виджеты:**
   - **Лунные фазы:** Добавлен компактный блок с иконками лунных фаз (Новолуние, Растущая, Полнолуние, Убывающая и т.д.), рассчитываемый динамически по текущей дате.
   - **Атмосферное давление:** Переведено из гектопаскалей (гПа) в привычные **мм рт. ст.**
   - **Осадки:** Добавлен блок отображения текущих осадков в миллиметрах (мм) в сетке подробностей.
   - Пустая ячейка видимости удалена.
5. **Хостинг и автоматизация:** 
   - Проект развернут на **Vercel** через отдельный репозиторий `weather-clean`.
   - Настроена кнопка «Обновить» и фоновое автообновление данных каждые 15 минут.
